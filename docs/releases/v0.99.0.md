# Copicker v0.99.0

Copicker `v0.99.0` is the first public pre-release that packages the complete six-model selector, persistent in-app settings, no-task selection support, configurable placement, and final native-aligned settings geometry.

This is an immutable annotated source release. The exact package commit is resolved by `v0.99.0^{commit}`. CLI and plugin report `0.99.0`; renderer compatibility remains independently versioned at `0.12.8`; settings schema remains `1`; and the settings document remains `ui://copicker/settings/v2.html`.

## Highlights

- Adds the detached body-level Shadow DOM rail beside Codex's compact first-level model/reasoning picker while excluding the full-width composer list.
- Supports Sol, Terra, Luna, Daybreak Blue, GPT-5.5, and GPT-5.3 Codex Spark in a fixed configurable order.
- Supports exact model-specific effort counts, catalog-resolved model IDs, and catalog-resolved Fast tier behavior.
- Keeps Daybreak and Codex Spark non-Fast and presents unsupported models such as GPT-5.4 and GPT-5.4 Mini as empty centered `Other` state.
- Supports click, horizontal drag, Up/Down/Left/Right, and Space interactions with confirmed rollback on unavailable or failed changes.
- Uses `thread/settings/update` plus `thread/settings/updated` for an existing task and the exact official Model/Effort/Speed controls before a task exists.
- Adds top, left, and right placement, nested-menu collision avoidance, latched no-flicker movement, pointer-gated side restoration, and guarded viewport clamping.
- Adds persistent CoPicker settings under Codex Integrations with enablement, six model toggles, placement, Codex/system/light/dark appearance, autosave, and explicit Apply now.
- Uses one revisioned atomic `0600` settings file and deduplicates native plugin and injected compatibility-fallback entries.
- Aligns the settings page to the measured official Codex scroll viewport, 20-pixel panel inset, 768-pixel content column, and 24/28.8-pixel page-heading geometry.

## Safety and privacy

- Does not modify, replace, unpack into, or re-sign `/Applications/ChatGPT.app`.
- Preserves the official bundle identity, signature, permission relationships, Keychain groups, App Groups, and update path.
- Keeps Inspector on `127.0.0.1`, fails closed on unknown listener ownership, and schedules closure immediately after each bounded action.
- Keeps the default CLI/status path read-only and automatic injection opt-in through a user LaunchAgent.
- Makes no external request from the injected payload or settings document.
- Does not read, log, or persist conversation text, composer text, task contents/IDs, authentication data, cookies, or tokens.

Private Codex DOM, Electron fuses, plugin routing, and app-server behavior remain version-sensitive. A later Codex desktop build requires independent compatibility and UI checks.

## Install

Install Apple's command-line tools if needed, clone the immutable tag, and run the installer as the logged-in user:

```bash
xcode-select --install
git clone --branch v0.99.0 --depth 1 https://github.com/Wineondili/copicker.git
cd copicker
./script/install.sh
```

Do not use `sudo`. The official Codex desktop app must be at `/Applications/ChatGPT.app`, and the `codex` CLI must be available. Loading the opt-in watcher may inject an already-running Codex PID, but the installer never terminates or restarts Codex.

This pre-release is source-distributed. GitHub supplies standard source archives, and no unsigned or non-notarized prebuilt executable is attached. Build natively on each target Mac.

See [installation.md](../installation.md) for prerequisites, verification, permissions, updates, preference migration, rollback, recovery, and uninstall. See [accepted-baseline.md](../accepted-baseline.md) for the exact model matrix, requirement IDs, geometry, measurements, and compatibility anchors.
