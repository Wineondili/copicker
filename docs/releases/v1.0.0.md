- Preserves the original click/drag easing while committing the exact release cell, independently of animation progress.
- Adds Astra, synchronizes seven-model visibility settings, and keeps Luna limited to the five effort levels actually exposed by the verified native picker.
- Displays the first four rail labels as `6-Astra`, `5.6-Sol`, `5.6-Terra`, and `5.6-Luna`, independently of internal model identity. Updates the standalone single-HTML preview too.
- Marks Codex Spark `Retiring` based on [Tibo's 2026-09-11 announcement](https://x.com/thsottiaux/status/2098300998968357218). No precise shutdown date is inferred, and the notice does not disable selection while the official catalog still permits it.

- Fixes native settings background and vertical spacing by owning the page surface outside the sandbox's body-padding reset. Adds the native 46 px toolbar region and 20 px scroll insets without duplicating that space in the fallback entry.
- Retains revision-checked local preferences, native/fallback deduplication, top/left/right placement, and catalog-resolved models and Fast tiers. Daybreak and Spark remain non-Fast.

## Install or update

Use a separate checkout of the exact release tag and run as the logged-in user:

```bash
git clone --branch v1.0.0 --depth 1 https://github.com/Wineondili/copicker.git copicker-v1.0.0
cd copicker-v1.0.0
./script/install.sh
```

Do not use `sudo`. The official app must be at `/Applications/ChatGPT.app`, and the `codex` CLI must be available. The installer may inject into a running Codex process but never quits or restarts it. Existing preferences are preserved. For an existing checkout containing your development changes, use the separate pinned clone above rather than resetting that checkout.

The native settings host may retain an old page even after MCP configuration refresh. After updating, manually quit and reopen Codex when your tasks permit, then open CoPicker settings. A successful resource read alone does not prove an old rendered page was replaced.

This release is source-distributed: GitHub supplies source archives, and no unsigned or non-notarized prebuilt executable is attached. Build natively on each target Mac. See the [v1.0.0 installation guide](https://github.com/Wineondili/copicker/blob/v1.0.0/docs/installation.md) for prerequisites, managed files, verification, and rollback.

## Safety and rollback

CoPicker does not modify or re-sign the official application bundle. Inspector is temporary and loopback-only; the default CLI action remains read-only, and automatic injection remains opt-in. The settings page has no external network dependency. Publication does not change the repository's existing license terms.

`v0.99.0` remains the immutable previous six-model pre-release; the historical full-runtime anchor is `c127509`. Those older refs may not work with the redesigned current picker. Use the rollback procedure in the installation guide and verify against the intended Codex build rather than assuming an older ref is universally compatible.
