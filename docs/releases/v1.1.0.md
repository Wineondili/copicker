# Copicker v1.1.0

Stable, full-feature source release containing renderer `0.12.21`, settings schema 1, and MCP settings resource v5. CLI/plugin distribution version is `1.1.0`.

## Changes

- Adds GPT-6 Sol and GPT-6 Luna with separate generation-specific preference keys and catalog-resolved model IDs. Sol has six effort levels; Luna has five. Both support catalog-resolved Fast.
- Uses exactly the same fill and text gradients for both Sol generations, and likewise for both Luna generations. Preserves existing rail geometry, click/drag easing, and release-coordinate selection.
- Removes GPT-5.3 Codex Spark from the selector, settings page, and standalone preview. Reading old settings removes only its retired key in memory; Spark-only visibility falls back to the existing default rows. Other preferences and revisions remain intact, and reading does not rewrite the file.
- Marks GPT-5.5 `Retiring` while preserving its four efforts, Fast support, and normal availability checks. No shutdown date is assumed and no scheduled local cutoff is introduced.
- Synchronizes all eight rows across the renderer, settings UI/backend, and preview. Resource v5 retains v4/v3/v2 read aliases. Existing visibility defaults remain 5.6 Sol/Terra/Luna; enable the new rows in settings.

## Install or update

Use a separate checkout of the exact release tag:

```bash
git clone --branch v1.1.0 --depth 1 https://github.com/Wineondili/copicker.git copicker-v1.1.0
cd copicker-v1.1.0
./script/install.sh
```

Run as the logged-in user, never with `sudo`. The official app must be at `/Applications/ChatGPT.app`; a plugin-capable `codex` CLI is required. Installation may inject into a running app but never quits or restarts it. Existing MCP connections/pages may retain cached resources: if the settings entry fails after updating, manually quit and reopen Codex when ongoing tasks permit.

This release is source-distributed: GitHub supplies standard source archives, with no unsigned or non-notarized prebuilt executable attached. Build on the target Mac. See [installation](https://github.com/Wineondili/copicker/blob/v1.1.0/docs/installation.md) for source-only builds, prerequisites, managed artifacts, and rollback.

## Safety and history

CoPicker does not modify or re-sign the official application bundle. Inspector is temporary and loopback-only; automatic injection remains opt-in. Old tags/releases, including `v1.0.0`, remain unchanged. Older releases do not include the eight-model update and may not read preferences containing new-generation keys. Publication does not change existing license terms.
